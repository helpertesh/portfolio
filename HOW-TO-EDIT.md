# How to edit your portfolio

Everything lives in one file: `index.html`. Open it in VS Code, use **Ctrl+F** to find the section, change the text, save, refresh the browser. The `New folder` Flask version reads its text from `New folder/config.py` instead, so edit that file if you deploy that version.

---

## 1. Add a project

Find the comment `HOW TO ADD A PROJECT` in `index.html`. Below it is the projects grid. Copy this block and paste it before the "More on GitHub" card:

```html
<article class="project-card reveal">
    <a class="project-thumb" href="https://YOUR-LIVE-SITE.netlify.app" target="_blank" rel="noopener" aria-label="Open My Project live site">
        <img src="assets/my-project.jpg" alt="My Project screenshot" loading="lazy">
        <span class="overlay"><span><i class="fas fa-arrow-up-right-from-square"></i> View live site</span></span>
    </a>
    <div class="project-body">
        <h3>My Project</h3>
        <p>One or two sentences on what it does and who it is for.</p>
        <ul class="tags"><li>React</li><li>FastAPI</li><li>PostgreSQL</li></ul>
        <div class="project-links">
            <a href="https://YOUR-LIVE-SITE.netlify.app" target="_blank" rel="noopener" class="btn btn-primary btn-sm"><i class="fas fa-arrow-up-right-from-square"></i> Live demo</a>
            <a href="https://github.com/helpertesh/YOUR-REPO" target="_blank" rel="noopener" class="btn btn-ghost btn-sm"><i class="fab fa-github"></i> Source</a>
        </div>
    </div>
</article>
```

Then change:

| What | Where |
|---|---|
| Screenshot | Save a screenshot as `assets/my-project.jpg` and set `src="assets/my-project.jpg"`. Crop out the browser bar first. Keep it under 300 KB. |
| Live link | Both `href="https://YOUR-LIVE-SITE..."` lines. Use your Netlify, Vercel or Render URL. |
| GitHub link | `href="https://github.com/helpertesh/YOUR-REPO"`. |
| Title and text | The `<h3>` and `<p>`. |
| Tags | The `<li>` items. |

**No live link yet?** Replace the `<a class="project-thumb">...</a>` wrapper with a plain `<div class="project-thumb">` around the image, and replace the two buttons with:

```html
<span class="soon"><i class="fas fa-hammer"></i> In progress — demo coming soon</span>
```

**Make a project the big featured one:** add `featured` to the class (`class="project-card featured reveal"`) and add `<span class="project-kicker">Featured project</span>` above the `<h3>`. Only one card should be featured. Remove `featured` from the Hostel card if you promote a different one.

**Get a live link for a static project:** go to https://app.netlify.com/drop and drag the project folder in. Netlify gives you a URL. You can rename it under Site settings, then Change site name.

## 2. Add social links (LinkedIn, X, WhatsApp, Fiverr...)

Social icons appear in two places: the hero (search `FIND ME ON`) and the contact section (search `social-row`). Each icon is one line:

```html
<a class="icon-link" href="https://linkedin.com/in/YOUR-HANDLE" target="_blank" rel="noopener" aria-label="LinkedIn"><i class="fab fa-linkedin-in"></i></a>
```

Copy a line, change the `href` and the icon class. Icon names come from Font Awesome (https://fontawesome.com/icons):

| Site | Icon class |
|---|---|
| LinkedIn | `fab fa-linkedin-in` |
| X / Twitter | `fab fa-x-twitter` |
| WhatsApp | `fab fa-whatsapp` (link: `https://wa.me/254712919229`) |
| Instagram | `fab fa-instagram` |
| YouTube | `fab fa-youtube` |
| Fiverr | no icon; use `fas fa-briefcase` |
| Upwork | `fab fa-upwork` |

Also add any new profile URL to the `sameAs` list inside the `application/ld+json` script near the top. That is what search engines read.

## 3. Change your skills

Search for `02 — Stack`. Each card is one category. A skill is one line:

```html
<li><i class="fab fa-react"></i>React</li>
```

Add `class="hot"` to highlight a skill you want to stand out:

```html
<li class="hot"><i class="fab fa-react"></i>React</li>
```

The scrolling strip under the hero (search `id="ticker"`) is separate. Keep it to 10 to 12 items.

## 4. Add a job, internship, degree or certificate

## 5. Update the resume PDF

The "Download resume" buttons serve `Peter-Mutethia-Resume.pdf`. That file is generated by `make_resume.py` so it always matches the site.

1. Open `make_resume.py`.
2. Edit the dictionaries at the top: `PERSON`, `SUMMARY`, `SKILLS`, `PROJECTS`, `EXPERIENCE`, `EDUCATION`, `CERTIFICATIONS`. Education and certifications are empty right now, so those sections are hidden until you add something.
3. Run:

```
python make_resume.py
```

If you would rather use a resume made in Word or Canva, export it as PDF, name it `Peter-Mutethia-Resume.pdf`, and drop it in this folder. Nothing else needs to change.

## 7. The contact form

The form sends through EmailJS using the public key and template already in the file. For it to work on a new domain, log in at https://dashboard.emailjs.com, open **Account, then Security**, and add your site's domain (for example `your-site.netlify.app`) to the allowed origins. Without this, visitors see "Could not send".

---

## 8. Light and dark mode

The sun/moon button in the header switches themes and remembers the choice in the visitor's browser. Colours are defined at the top of the `<style>` block: the `:root { ... }` block is dark, `:root[data-theme="light"] { ... }` is light. Change `--accent` in both to re-colour the whole site.

## 9. Publish (deploy)

### Option A: Netlify drag and drop (easiest, free)

1. Run `python make_deploy.py`. It creates a `deploy` folder with only `index.html`, `assets` and the resume PDF.
2. Go to https://app.netlify.com/drop and sign in (GitHub login works).
3. Drag the `deploy` folder onto the page. In about a minute you get a link like `https://random-name-123.netlify.app`.
4. Rename it: **Site configuration, then Site details, then Change site name**. For example `petermutethia.netlify.app`.
5. Add that URL to EmailJS allowed origins (section 7) so the contact form works on the live site.
6. Put the URL in `website` in `make_resume.py` and re-run it, then redeploy so the PDF on the site has your link.

**To update the site later:** edit `index.html`, run `python make_deploy.py` again, open your site in Netlify, go to **Deploys**, and drag the `deploy` folder onto the page.

### Option B: Netlify connected to GitHub (auto-deploy on every push)

1. Create a repo on GitHub, for example `portfolio`, and push this folder to it.
2. In Netlify choose **Add new site, then Import an existing project**, pick the repo.
3. Set **Publish directory** to `.` (the repo root). Leave build command empty.
4. Every `git push` now redeploys the site automatically.

Add a `.gitignore` with these lines so backups and the Flask app's inbox are not published:

```
index.backup.html
index.zip
deploy/
New folder/data/
New folder/__pycache__/
New folder/.env
```

### Option C: GitHub Pages (also free)

Push to a repo, then in the repo go to **Settings, then Pages**, pick the `main` branch and `/ (root)` folder. The site appears at `https://helpertesh.github.io/REPO-NAME/`. The one catch: the resume download and the photo use relative paths, so keep `index.html`, `assets` and the PDF at the repo root.

### Custom domain (optional)

Buy a domain (for example on Namecheap or Truehost for a `.co.ke`), then in Netlify go to **Domain management, then Add a domain** and follow the DNS steps. HTTPS is set up automatically.

### Deploying the Flask version instead

Only do this if you want messages saved on a server. Push `New folder` to GitHub, then on https://render.com create a **Web Service** from the repo with:

- Build command: `pip install -r requirements.txt gunicorn`
- Start command: `gunicorn app:app`
- Environment variables: `SECRET_KEY`, and `SMTP_HOST`, `SMTP_USER`, `SMTP_PASSWORD` if you want emails.

## 10. WhatsApp

Every WhatsApp button opens a chat with you and pre-fills a greeting. The link looks like:

```
https://wa.me/254712919229?text=Hi%20Peter...
```

The number is your phone in international format with no plus sign or leading zero (`0712919229` becomes `254712919229`). To change the greeting, search `wa.me/254712919229?text=` in `index.html` and edit the text after `text=`. Spaces must be written as `%20`. The Flask version keeps both in `config.py` as `whatsapp` and `whatsapp_message`.

The floating green button is the `wa-float` link near the bottom of `index.html`. Delete that one line if you do not want it.
